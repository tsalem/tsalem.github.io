    Teaching

    At Purdue University, I teach courses spanning programming, software development, artificial intelligence, machine learning, and cybersecurity. My teaching emphasizes hands-on problem solving, conceptual understanding, and connecting foundational computing concepts with practical applications.

    Current & Recent Courses

    CNIT 57200 · Artificial Intelligence Applications in Cybersecurity

    A graduate course exploring the application of artificial intelligence and machine learning techniques to cybersecurity problems.

    CNIT 10500 · Introduction to C Programming

    An introductory programming course covering fundamental problem solving and programming concepts using the C language.

    CNIT 15501 · Introduction to Software Development Concepts

    An introductory software development course using Python, with an emphasis on programming fundamentals, problem solving, and hands-on development.

    CNIT 17500 · Visual Programming

    An introductory course focused on programming concepts and application development through visual programming environments.

    Graduate & Special Topics
